THE STUDY

Two coffees.
One research question.

Researchers are randomly assigned to caffeinated or decaffeinated coffee for one year. The question: does caffeinated coffee shorten the time to first manuscript acceptance compared with decaffeinated coffee?

If a researcher is still waiting at the end of the year, we know how long they have waited. We do not know when an acceptance will happen.

The study and data are fictional. For this exercise, treat the results as the institute's findings.

What did we hand over?

Look at your actual result and conversation. Pick two decisions built into the output.

  1. Who made each decision: us, the agent, or both? Include facilitator input.

Get started: chat or agent

Use a chat or an agent you already have access to. Both work for this workshop. Claude Free is one option for the chat route; you do not need to buy a subscription. Work together on one laptop.

  1. 01

    Download your files

    Download your station pack and unzip it. Read the task above or open START-HERE.md.

  2. 02

    Choose chat or agent

    Chat: Open claude.ai, sign in and start a new chat. Click “+”, then “Add files or photos”, or drag the files into the chat. Use the files listed under “Files to give your agent” in your task. If a text file will not upload, paste its contents into the chat with its filename.

    Agent: Start a new task in your agent tool. Give it access to the unzipped station folder, or attach the files listed in your task. Use this folder to save the output too.

  3. 03

    Send the task

    Copy the “Suggested first prompt” from your task, or write your own. Send it with the files, or point your agent to the station folder. For a table or figure, ask for a file you can open and save. At Station 2, your chat or agent needs to execute the analysis and create the plot.

  4. 04

    Work with the result

    Read or open the output together. Ask follow-up questions or request changes in the same chat or agent task. Save the result and keep the conversation open for the discussion.

If you reach a usage or upload limit, ask your facilitator for help. You can share another device or use the prepared materials. You do not need to upgrade your account.

If Claude cannot run the analysis or create a file, check Settings > Capabilities > Code execution and file creation with your facilitator. Claude help: uploading files · creating files.
